## Source notes

The National Park Service source informs historic-interior preservation. The U.S. Access Board ADA standards are cited for door accessibility concepts **only in facilities to which those standards apply**, not as a universal rule for single-family homes. The International Code Council's 2021 IRC is a published example of opening protection; current local requirements must be checked for a particular project.
